## Installation

Clone the repository:

```bash
git clone https://github.com/<your-username>/qryptex.git
```

Navigate into the project:

```bash
cd qryptex
```

Install dependencies:

```bash
pnpm install
```

Start development server:

```bash
pnpm run dev
```

---

## Build For Production

```bash
pnpm run build
```

Preview production build:

```bash
pnpm run preview
```
