## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/sureshKrishna05/Qryptex-V2.git

# Navigate to project directory
cd Qryptex-V2

# Install dependencies
pnpm install

# Start development server
pnpm run dev
```

## 🏗️ Build

```bash
pnpm run build
```
